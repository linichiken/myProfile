# myProfile

獨立設計師風格的個人簡介頁，後現代拼貼視覺，純 HTML / CSS / JS 打造。

## 特色

- 拼貼版面：卡片以不同角度旋轉、粗黑邊框搭配硬陰影
- 自訂滑鼠游標，懸停在按鈕上會放大變色
- 滑鼠視差：主視覺區塊會依游標位置微幅偏移
- 背景巨大輪廓字緩慢漂移、點狀紋理持續位移
- 頂部／底部跑馬燈文字
- 區塊捲動進入視窗時的角度微調動畫
- 已處理 `prefers-reduced-motion` 與觸控裝置，動態效果只在支援的環境啟用

## 檔案結構

```
index.html   頁面結構
style.css    樣式
script.js    互動效果（游標、視差、捲動動畫）
```

## 使用方式

直接用瀏覽器開啟 `index.html` 即可預覽。

內容中所有用「方括號」標示的文字（例如 `[你的名字]`、`[you@example.com]`）都是待填入的預留位置，直接在 `index.html` 裡搜尋並替換成自己的資訊即可，例如姓名、職稱、簡介、興趣標籤與聯絡方式。

## 部署

可直接透過 GitHub Pages 發佈：至儲存庫 Settings → Pages，選擇 `main` 分支即可上線。
